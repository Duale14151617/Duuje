About POLICE HQ

Headquarters administration system, sample build.

What this is

POLICE HQ is a private web application for headquarters administration: personnel records, organization structure, logistics, vehicles, training, reporting and an audit log. It is used by a small number of authorized staff. It is not a public website and offers no public sign-up.

This deployment is a sample build. It contains synthetic data only and is not approved for operational use. Approval from the Ministry of Security Puntland is pending.

Access

Accounts are created by a system administrator. Privileged accounts must use an authenticator app (multi-factor authentication). If you were given an account and have trouble signing in, contact the administrator who issued it, or use the contact address above.

Email sent by the system

The system sends only account emails to people who hold an account: email verification codes, password reset links and security notices (for example when a password is changed). It sends no marketing or promotional email.
